# Campo
Input de 52px en píldora sobre `superficie-suave`, borde `linea`; con foco toma el borde `acento`.

- `label` (visible siempre que el campo esté solo; el buscador de la lista puede ir sin label visible pero con `id` y label oculto), `icono`, `placeholder`, `tipo`, `ayuda`, `error`, `accion` (un `BotonIcono` dentro, p. ej. mostrar contraseña).

El error se escribe como lo diría una persona: "Ese legajo no existe", no "Error 401".
