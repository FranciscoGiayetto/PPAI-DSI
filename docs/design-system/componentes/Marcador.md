# Marcador
Cada bolsín Enviado es un camioncito `sello` sobre el mapa (40px; 52px seleccionado con aro `acento` y halo). Es un `button` con `aria-label` "Bolsín N hacia CM". El origen es un punto `azul` con aro `crema`; las CM destino, aros `info`.

En Google Maps: usar `AdvancedMarkerElement` con este HTML como contenido, y el estilo de mapa con los colores `mapa-*`.
