# Dialogo
Diálogo de confirmación en vidrio sobre `velo`. Título en display, una frase que dice **qué** pasa y **a quién**, y dos acciones: la negativa a la izquierda (`secundario`, "No, gracias" → flujo A5) y la positiva a la derecha (`primario`).

`role="dialog"`, `aria-modal`, foco atrapado y Esc para cerrar al implementarlo.
