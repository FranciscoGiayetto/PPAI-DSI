# Boton
Botón en forma de píldora, 52px de alto.

- `variante`: `primario` (relleno `sello`, la acción principal de una pantalla; una por pantalla), `marca` (solo en el login, usa `marca` + `sobre-marca-texto`), `secundario`, `fantasma` (acciones de texto), `peligro` (reintentos y acciones sobre errores).
- `icono` / `iconoFinal`: nombre de `Icono`. `ancho`: ocupa todo el ancho. `deshabilitado`.

Textos en verbo y cortos: "Avisarle al gerente", "Ingresar", "Reintentar". Nada de "Aceptar" genérico.
