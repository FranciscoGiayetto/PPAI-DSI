# Trayecto
Barra de recorrido del bolsín: origen (punto `azul`), destino (aro `info`), tramo hecho en `acento` y el camioncito sobre un marcador `sello`. Con `error`, el marcador es rojo con "?".

`progreso` (0–100) es aproximado (distancia en línea recta); es una ayuda visual, no un dato del sistema.
