# Vidrio
La superficie de Bolsines: semitransparente (`superficie-vidrio`), desenfoque `vidrio-blur` + `vidrio-saturacion`, borde `linea`, brillo superior y sombra `sombra-vidrio`, radio `radius-xl`.

**Solo sobre algo con color o movimiento** (el mapa, el panel de marca). Sobre un fondo liso el vidrio no se ve: ahí usar `superficie-suave` o nada.
