# BarraNav
Barra de navegación de vidrio.

- `variante: "escritorio"`: flotante arriba al centro. Logotipo a la izquierda; la sección activa es una píldora `acento` con ícono + texto; el resto, solo ícono (con `aria-label`). `extra` agrega elementos al final (CM del usuario, `InterruptorTema`, avatar).
- `variante: "movil"`: tab bar flotante abajo, al alcance del pulgar, ícono + texto en todos los ítems.
- `items`: `[{id, label, icono, href}]`, `activo`, `onSelect`.

Seguimiento usa el ícono `camioncito`; Bolsines usa `bolsa`.
